# src/ — the v2.0 module tree (Phase 1)

`app.js` at the repo root is GENERATED by `node build.js` from these files, in
manifest order. Never edit `app.js` directly. See `docs/PHASE1-MAP.md` for the
full dependency map, classifications (KEEP / REFACTOR / REPLACE LATER) and the
phase gates. Empty directories (core/, data/, decisions/, mini-league/, ui/)
are the destinations of the next extraction tranches.
