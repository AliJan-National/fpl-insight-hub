# ⚽ FPL Insight Hub — 2026/27

Free FPL analytics on open data. One performance model everywhere (ticker ranking → form-adjusted FDR → wildcard/radar/captain/copilot).

**🏆 Mini League Command Center:** loads your league, studies the rivals that matter, auto-selects strategy (DEFEND / CONSOLIDATE / ATTACK / ALL-IN), and answers everything relatively: chip battles, threats, differentials, SAFE/BALANCED/DIFFERENTIAL captaincy, transfer & hit verdicts, win-probability estimates, weekly roadmap. The same ML lens appears inside My Team, Wildcard Lab and the Copilot.

| Tab | What it does |
|---|---|

| My Team | Best XI, verdicts, captaincy, game plan — with ML lens when league loaded |
| Wildcard Lab | Optimal £100m team (max 3/club) + overlap + league differentials |
| 🤖 Assistant | Copilot incl. "how do I win my mini league?", "should I take a hit?" |
| 🏆 Mini League | Command Center (above) |
