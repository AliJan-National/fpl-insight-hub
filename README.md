# ⚽ FPL Insight Hub — 2026/27

Free FPL analytics dashboard on open data. No paywall.

**One performance model everywhere:** teams ranked by ppg + xG + shots (Fixtures ticker) feed the form-adjusted FDR used by the Wildcard Lab, Transfer Radar, captaincy, game plan and the Copilot — every tab agrees.

| Tab | What it does |
|---|---|
| **Overview** | Table, top scorers, results with xG |
| **My Team** | Best XI, verdicts, captaincy, budget-checked moves, GW game plan, chips |
| **Wildcard Lab** | Optimal £100m team weekly (max 3/club) + overlap with your squad |
| **🤖 Assistant** | Copilot with full dataset + your team |
| **Transfer Radar / Captain & Prices** | Signals with form-table reasons |
| **Players** | Sortable explorer |
| **Fixtures** | Season ticker: ranked teams, results GW1–3 (W/D/L colours), form-adjusted FDR GW4–10 |
| **Injuries & News** | Flagged players |

Data: [olbauday/FPL-Core-Insights](https://github.com/olbauday/FPL-Core-Insights) + official FPL API. Update: `bash refresh.sh`. FPL data © Premier League. Unofficial fan project.
